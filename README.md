# or_tool_demo

CSVの数値データから、合計が指定した目標値と一致する組み合わせをCP-SATソルバー(OR-Tools)で探索し、結果をExcelに出力するツールです。

## セットアップ手順

1. [python.org](https://www.python.org/downloads/) からPython 3.12以上をダウンロードしてインストール
   1. バージョン（3.12以上）のDownload > Windows installerの順でダウンロード
   2. ダウンロードファイルを右クリック > 管理者として実行
   3. インストーラの最初の画面で **「Add python.exe to PATH」** にチェック
   4. Install Now
2. Pythonがインストールされたことを確認
   1. コマンドプロントを開き、`python -V`を実行
   2. 以下のように表示されたらOK
      ```
      Python 3.XX.XX
      ```
      ※もし表示されない場合は環境変数のPathが通っていない可能性があるため、PythonインストーラのModifyから`Add Python to enviconment variables`を実行するか、直接Windowsの環境変数を設定してください
3. このリポジトリ一式をコピー
   1. このリポジトリページにアクセス
   2. `<> Code`をクリック
   3. `Download ZIP`をクリック
   4. ダウンロード完了後、任意のフォルダへ移動
4. ↑のフォルダを表示し、`setup.bat` をダブルクリックで実行

## 実行方法

### データ

`data\input.csv` に `タイトル`, `数値` の2列でデータを用意してください。

```
"タイトル","数値"
"タイトル001",2314606
"タイトル002",7866936
```

### 実行方法

セットアップ後は `run.bat`をダブルクリック実行してください。

#### 入力する値

- `target`: 合計を一致させたい目標合計値。複数指定する場合はスペース区切りで入力してください(例: `100 200 300`)。複数指定した場合、各目標値のグループで使う行が重複しない組み合わせを探索します。

結果は `data\result.xlsx` に出力されます(Summaryシート・Detailsシート)。`target`列でどの目標値のグループかを確認できます。  
設定ファイル`config.ini`で出力先や件数上限などを変更できます(詳細は「設定ファイル」参照)。

## 設定ファイル

リポジトリ直下の `config.ini` で以下の値を変更できます。メモ帳などで直接編集してください。

| 項目 | 内容 | デフォルト |
| --- | --- | --- |
| `csv_file` | 入力データのCSVパス | `data/input.csv` |
| `output_file` | 結果を書き出すExcelファイルのパス | `data/result.xlsx` |
| `limit` | 収集する解の最大件数 | `100` |
| `num_search_workers` | CP-SATソルバーの並列探索ワーカー数 | `4` |
| `amount_column` | 数値を表すCSV列名 | `数値` |
| `title_column` | タイトルを表すCSV列名 | `タイトル` |

## その他
### 探索負荷軽減／高速化したいとき
`config.ini`の`num_search_workers`の値を変更してください。  
値が小さいほど並列の探索数が減り、負荷が軽減されます。  
値が大きいほど並列の探索数が増えることで、短時間での探索を期待できますが負荷が増します。
